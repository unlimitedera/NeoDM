**Which file do I download?** Download only **NeoDM-Setup-1.11.0.msi** and ignore every other file in the Assets list (click "Show all assets" if you do not see it). The other files are browser extension packages, checksum files and source code for people who need them. Step by step help: [Install guide](https://github.com/unlimitedera/NeoDM/blob/main/docs/INSTALL.md)

Windows may show "Windows protected your PC" because the installer is not yet signed with a paid certificate. Click **More info**, then **Run anyway**.
